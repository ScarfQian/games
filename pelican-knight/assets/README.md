# 固定资产

图形源为 [sprites.svg](sprites.svg)，身份与修订登记在 [catalog.json](catalog.json)。既有资产编号、挂点与图形保持原公开版本。

[资产图鉴](../docs/assets.html) 展示人物、敌人、武器、帽巾、车辆与建筑。修改图形源或目录后，使用 [sync_assets.py](https://github.com/ScarfQian/games/blob/main/pelican-knight/tools/sync_assets.py) 同步内嵌资源：

```sh
python3 tools/sync_assets.py
```

从该游戏目录运行，无需第三方依赖。旧资产历史及详细说明见[原仓库](https://github.com/ScarfQian/pelican-knight/tree/4ce07ded5835f9abb83c41018b4ea4f439b46a8b/assets)。
