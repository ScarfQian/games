# 科研大冒险

当前 **0.0.1 · 设计阶段**，没有可运行的游戏。

从小学启程，在考试、专业选择、研究课题与学术生涯中构筑成长路线。每关对应一个阶段，通过卡片改变打法，阶段间保留本局构筑，整局结束后清零。
