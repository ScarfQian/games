# 鹈鹕骑士 · 波次远征

当前版本 **0.4.0**，来自[原公开仓库的固定版本](https://github.com/ScarfQian/pelican-knight-waves/tree/16d83f48851de82f567050f50144652a880bdd92)。源码与现有图形保持该版本；原仓库、历史快照和旧网址继续保留。

[进入游戏](https://scarfqian.github.io/games/pelican-knight-waves/) · [游戏大厅](https://scarfqian.github.io/games/)

本游戏为单文件 HTML，直接打开 `index.html` 即可运行，无需安装依赖。CSS、SVG、JavaScript 与合成音效均内嵌。存档继续使用原有键，不与其他游戏混用。

可复用图形在 `assets/sprites.svg`，资产身份与修订在 `assets/catalog.json`。修改固定资产后使用 `python3 tools/sync_assets.py` 同步游戏与[资产图鉴](docs/assets.html)；单纯玩法修改在 `index.html` 中进行。

本目录不包含原仓库的内部开发日志或历史快照副本；历史内容可通过上面的固定来源链接查看。
